# Continuité du Centre Intelligences

Le Centre Intelligences utilisé par la direction reçoit un onglet Images, voix et transcription réutilisant les composants privés et le gateway MAIN existants. La mémoire utilisateur est également accessible depuis son onglet Mémoire. Aucun onglet, moteur, modèle ou contrôle existant supprimé ; aucun partage SHOP.

Le registre de livraisons conserve les preuves des PR470/471, et les fondations enregistrent trois décisions/leçons sourcées du Fondateur. Le bootstrap existant écrit ces connaissances en base une seule fois. Ce ne sont pas des données commerciales inventées ni une absorption des connaissances d’un modèle externe.

Validation requise : TypeScript complet, build Railway, suites médias/transcription existantes. Les essais réels avec le PDG sont séparés, à effectuer lorsqu’il est disponible.
